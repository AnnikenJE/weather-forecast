# Claude Rules for Weather Forecast

## Project context
Flask app that fetches weather data from a weather API. First self-initiated Python project.

## Language
Always respond in Norwegian unless the user writes in English.

## Code style
- Use simple, readable solutions — don't over-engineer
- Write minimal or no comments in code; names should say enough

## Learning
- The user is learning Flask — do not generate finished code without her understanding and trying first

## Git
- Do not commit or push unless asked
- Suggest commit messages in English

## Security
- No API keys or secrets in code — use .env
- Remind if .env is missing from .gitignore
